核心功能

从截屏到结构化信息，一个工具打通

🖥️

区域截图

F2 全局快捷键（可自定义），拖出选区可调整四边/四角与整体位置，回车/双击确认；冻结帧捕获，所见即所得，多显示器与高 DPI 适配。

✏️

标注编辑

矩形、箭头、画笔、荧光笔、文字标注，撤销/重做；编辑窗口精确覆盖在截图原位，外发光边框标识区域。

📌

贴图置顶

截图（含标注）一键变为置顶悬浮图，可任意拖动、支持多张贴图，双击关闭——对照填写、比图神器。

🔍

本地 OCR

基于 Windows.Media.Ocr 的离线文字识别，中英文混排，无需联网、无需 API Key，秒级出结果。

✨

AI 视觉识别

截图发给支持视觉的大模型（推荐免费的 agnes-2.5-flash），按 Markdown 输出：表格转 Markdown 表格、代码进代码块。System Prompt 可自定义。

📋

一键复制

图片同时写入 DIB 与 PNG 双格式，粘贴到聊天窗口、文档、编辑器均可；识别文本一键复制。

快速上手

三步开始

下载安装

从 GitHub Releases 下载 MSI 安装包，按提示完成安装；安装包附带 SHA256 校验值。

按 F2 截图

任意界面按 F2 拖出选区，调整后按回车或双击确认，进入标注编辑器。

贴图或识别

点图钉贴图置顶，或点紫色图标本地提取文字；配置好模型后点星芒图标让 AI 输出 Markdown。

快捷键

可在设置中自定义

快捷键功能
F2（默认）开始区域截图
Esc / 右键取消截图 / 关闭编辑器
Ctrl+Z / Ctrl+Y撤销 / 重做标注
双击贴图关闭该贴图

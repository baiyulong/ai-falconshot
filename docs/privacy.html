FalconShot 隐私政策

生效日期：2026 年 9 月 2 日

FalconShot 是一款开源的 Windows 截图工具（Rust + Tauri 2 构建），其源代码公开在 GitHub。本政策说明应用在你的设备上存储、发送哪些数据，以及你可以如何控制。

一句话版本：截图默认只保存在你的电脑上；应用不收集遥测、不做统计、不投放广告；唯一可能把截图内容发送到网络的功能是“AI 识别”，且仅在你主动点击、发送到你自己配置的模型服务商时才会发生。

1. 本地存储的数据

  • 截图文件：每次截图会保存在本地 %APPDATA%\FalconShot\captures\（含标注后覆盖）。应用不会自动删除或上传这些文件；使用“保存”按钮可另存到你选择的位置。删除由你或系统清理完成。
  • 设置文件：%APPDATA%\FalconShot\settings.json 保存你的偏好（界面语言、默认保存位置/格式、快捷键等）。若你填写了 AI API Key，它同样以明文保存在该文件中，仅在你本机使用，不会上传到 FalconShot 的任何服务器（本产品没有服务器）。你也可以改用环境变量 FALCONSHOT_AI_KEY，从而避免密钥写入磁盘。
  • 历史记录：应用可能在本机维护截图历史索引；其中的记录不离开你的设备。请注意，“加密历史”等隐私设置项在当前版本中尚未生效。

2. 网络发送的数据

  • AI 识别（可选）：当你在编辑器中点击“AI 识别”时，该截图会被发送到你在设置中自行配置的、支持视觉的模型接口（OpenAI 兼容，默认指向 DeepSeek），同时发送你的模型名与提示词。你的 API Key 仅作为请求头发送给该服务商。是否使用、使用哪家服务商，完全由你决定并自行对第三方处理负责。
  • 本地 OCR（可选）：点击“提取文本”时，截图仅在设备本地由 Windows 系统组件识别，不发送到网络。
  • 除此之外，应用没有任何遥测、统计、崩溃上报或自动更新功能，也不会在后台发起网络请求。

3. 剪贴板

应用只在你主动点击“复制”时写入剪贴板，从不读取剪贴板内容。

4. 权限与全局快捷键

默认的全局快捷键（F2）只在你的设备本地触发截图流程；应用不会因此上传任何内容。

5. 第三方

本产品不使用广告或第三方跟踪 SDK。若你启用 AI 识别，截图、提示词将与你选择的第三方 AI 服务商共享，其数据处理适用该服务商的政策。

6. 你的权利与联系

你随时可以删除 %APPDATA%\FalconShot\ 目录来清除全部本地数据。本政策如有变更会在此页面更新。项目主页：baiyulong.github.io/ai-falconshot。

FalconShot is an open-source screenshot tool for Windows, built with Rust and Tauri 2; its source code is public on GitHub. This policy explains what data the app stores or sends from your device, and how you can control it.

TL;DR: Screenshots stay on your computer by default. The app has no telemetry, no analytics and no ads. The only feature that can send screenshot content over the network is "AI recognition", which happens only when you click it and sends to the model provider you configured yourself.

1. Data stored locally

  • Screenshots: each capture is saved to %APPDATA%\FalconShot\captures\ locally (overwritten after annotation). The app never uploads or auto-deletes them; the "Save" button lets you save elsewhere. Deleting them is up to you or system cleanup.
  • Settings: %APPDATA%\FalconShot\settings.json holds your preferences (UI language, default save location/format, hotkeys, …). If you enter an AI API key, it is stored in plain text in that file and used only on your machine — it is never sent to any FalconShot server (there is none). Alternatively, use the FALCONSHOT_AI_KEY environment variable so the key is never written to disk.
  • History: the app may keep a local index of past captures; it never leaves your device. Note that privacy settings such as "encrypt history" are not effective yet in the current version.

2. Data sent over the network

  • AI recognition (optional): when you click "AI recognition" in the editor, that screenshot is sent to a vision-capable model endpoint you configured in Settings (OpenAI-compatible; defaults to DeepSeek), together with your model name and prompts. Your API key is sent only as a request header to that provider. Whether you use it, and with which provider, is entirely your choice; processing by that third party is subject to their policy.
  • Local OCR (optional): clicking "Extract text" recognizes the screenshot on-device via a Windows system component — nothing is sent to the network.
  • Otherwise the app has no telemetry, analytics, crash reporting or auto-update, and makes no background network requests.

3. Clipboard

The app writes to the clipboard only when you click "Copy". It never reads clipboard content.

4. Permissions & global hotkey

The default global hotkey (F2) only triggers the local capture flow on your device; nothing is uploaded because of it.

5. Third parties

This product uses no ads and no third-party tracking SDKs. If you enable AI recognition, screenshots and prompts are shared with the third-party AI provider you choose; their data handling is governed by that provider's policy.

6. Your rights & contact

You can delete the %APPDATA%\FalconShot\ folder at any time to remove all local data. Any changes to this policy will be posted on this page. Project homepage: baiyulong.github.io/ai-falconshot.
